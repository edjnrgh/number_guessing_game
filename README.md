# Number Guessing Game

A simple game where you guess a number between 1 and 100.

## How to play
1. Type a number and click Guess.
2. You'll be told if it's too high or too low.
3. Keep guessing until you get it right.
4. Click Try Again to play again.

## Built with 
HTML, CSS and Javascript
